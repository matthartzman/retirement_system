# Documentation index

Layout rule (see "Documentation layout" in `reference/CONTRIBUTING.md`):
`reference/` is living and must be true today; `future/` is planned, not yet
built; `archive/` is shipped, superseded or historical. The old top-level `docs/`
directory is gone; do not add files there (a test fails if you do). Every spec or
plan in `future/` and in `archive/superpowers/` dated 2026-09-16 or later carries a
`Status:` line (draft, approved, implemented, superseded or planned), also tested.

## future/

`future/superpowers/plans/` and `future/` hold designs and plans not yet implemented
(or not yet verified as implemented; read each file's `Status:` line first). The
specs and plans that used to sit in `docs/superpowers/` were all checked against the
code and commit history in WI-016 and none was found unshipped, so they are in
`archive/superpowers/`.

Shipped on 2026-11-11 (W3-08): the Financial Trends designs for time scope, Live Snapshot, remote
access, annuity plan values, financial-insight readability and recent projections moved from
`future/superpowers/plans/` to `archive/superpowers/plans/`, each with a merge reference in its
`Status:` line. The Trends drill-down design and plan moved too (parts d, a to c and e merged as PRs #286, #288, #289).

## archive/

`archive/reports/` dated system reviews and wave plans; `archive/superpowers/`
shipped specs and plans; `archive/legacy/` older phase notes; the rest is
superseded planning material and inventories. `archive/PLAN_METADATA_SCHEMA.md` is the
schema for a `plan_metadata.json` file that no code reads or writes (archived in WI-016
after a search of `src/`, `tools/`, `frontend/`, `scripts/` and `tests/` found no use; two
tests only check the file if it happens to exist). `archive/superpowers/plans/perf-baseline-2026-09-17.json`
is the September workbook-build timing baseline; no tool or test reads it.
